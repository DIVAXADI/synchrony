## Features

- Zero ads, zero subscriptions
- Real-time audio sync (<100ms latency)
- Shared queue management
- Cloud-stored music library (Cloudflare R2)
- Midnight blue theme
- Mobile responsive
- No installation required

## Tech Stack

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Real-time:** Socket.io
- **Storage:** Cloudflare R2 (10GB free)
- **Hosting:** Vercel (free tier)

## Getting Started

1. Create a room or join with a code
2. Add songs to the queue from the library
3. Listen together in perfect sync
